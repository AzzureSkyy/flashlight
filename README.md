# Flashlight

Screen flashlight for Garmin Fenix 8 Solar 51mm by **AzzureSkyy**.

- Tap: white / red
- Swipe up/down or UP/DOWN: brightness
- Double tap, screen hold, or MENU: circular brightness dial

Install: copy `build/Flashlight.prg` to `GARMIN\Apps` on the watch.
