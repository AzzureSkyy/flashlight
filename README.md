# Flashlight

Flashlight for Garmin Fenix 8 Solar 51mm by **AzzureSkyy**. Drives the watch's built-in LED (white/red, low/medium/high, strobe); falls back to a screen light on devices without an LED.

- START: light on / off
- Tap: white / red
- Swipe up/down or UP/DOWN: brightness
- Double tap, screen hold, or MENU: circular dial (Low, Med, High, Strobe, Red, White)
- BACK: turn off and exit

Install: copy `build/Flashlight.prg` to `GARMIN\Apps` on the watch.
